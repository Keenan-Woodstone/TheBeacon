# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-09-04

### Added
- `CONSENT_LIFECYCLE.md` — the full Consent Ethic practice guide (four-stage lifecycle, worked examples, adoption guide).
- `README.md` — public landing page explaining the Consent Ethic and its open, non-obligatory ask to share it onward.
- `CHARTER.md` — project charter defining TheBeacon's scope as a standalone, public broadcast point for the Consent Ethic.
- `CLAUDE_ONBOARDING.md` — onboarding doc for agents/pilots working in this repo.
- `LICENSE` — CC BY 4.0 license covering the written material.
- `SIGNOFF_LOG.md` and Sign-Off end-of-session procedure, adapted from Docenmaster's.
- `BIBLIONMASTER.md`, `DOSSIERMASTER.md`, `YARDMASTER.md` and supporting `Dossiers/` structure and `tools/` scripts.
- Design decision record for the public discovery layer bootstrap (`Construction/Design-Decisions/2026-08-28-bootstrap-public-discovery-layer.md`) and the Sign-Off adoption trim (`2026-09-03-signoff-adoption-trim.md`).

### Notes
- No application code — TheBeacon is intentionally docs-only; it is meant to be read, not run.
- Rubric + "Letter from the Agent" work (tracked in issue #3) is out of scope for this release and carried forward separately.
